Orbit SC-97 — installable calculator web app 

The folder holds everything the app needs:
  index.html            the calculator
  manifest.webmanifest  app name, icons and colours for installing
  sw.js                 makes it work offline after the first visit
  icons/                home-screen icons

Install on your phone
  Android (Chrome): open the link, then menu (three dots) > Install app / Add to Home screen.
  iPhone (Safari):  open the link, then Share > Add to Home Screen.
